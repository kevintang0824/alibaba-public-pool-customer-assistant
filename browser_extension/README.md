# 阿里国际站公海客户开发助手

通用分享版 `v1.2.0`，适用于 Chrome 和 Edge。扩展在阿里国际站公海客户可见页面内工作，不读取隐藏接口，不绕过登录、验证码或安全验证。

## 主要功能

- 按页数和客户数扫描当前公海列表
- 默认轻量扫描，只读取客户表格行
- 跨页去重并生成固定处理队列
- 点击列表中的旺旺/TM 图标，填写自定义公司介绍语
- 话术支持 `{name}` 客户名和 `{company}` 公司名个性化变量
- 发送前核对聊天收件人
- 支持“测试 1 位”：只填入，不发送、不关闭聊天
- 单个客户没有旺旺入口时记录并跳过
- 暂停后保留进度，可从当前客户继续
- 关闭轻量模式后，可选择图片或视频素材
- 可切换为详情流程：进入详情、加为我的客户、打开旺旺

## 安装

1. 解压分享包，解压后不要移动或删除其中的文件。
2. Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的扩展文件夹，也就是包含 `manifest.json` 的目录。
6. 刷新已经打开的阿里国际站公海客户页面。

## 首次使用

1. 登录自己的阿里国际站账号并打开公海客户列表。
2. 在右下角面板填写自己的公司介绍语。通用版没有预设公司、姓名或产品。
3. 保持“轻量模式”“当前页快捷模式”和“发送前校验收件人”勾选。
4. 设置扫描页数和客户数，第一次建议 `1 页 / 5 位客户`。
5. 点击“1. 扫描客户”。
6. 点击“2. 测试1个（不发）”，人工核对客户和聊天输入框。
7. 核对无误后再点击“3. 开始群发”。

## 图片和视频

发送图片或视频时：

1. 选择图片或视频，插件会自动切换到图文模式并勾选素材发送。
2. 建议选择 1–2 张清晰的产品主图；新版会缓存解码结果并将多张素材合并为一次上传，减少连续群发时的卡顿。
3. 先测试 1 位客户，核对个性化话术和素材后再群发。

素材总大小限制为 `25MB`。建议每批只选择一个素材，并减少客户数量。

## 数据与隐私

- 介绍语、队列、进度和临时素材只保存在当前浏览器的扩展本地存储中。
- 扩展不包含个人姓名、公司话术、本机路径或账号密码。
- 扩展不上传使用日志到第三方服务器。
- 点击“清空队列”会清除当前队列和临时素材。
- 卸载扩展会删除该扩展在浏览器中的本地数据。

## 使用限制

- 仅在当前登录账号有权访问的可见页面上使用。
- 验证码、安全验证、登录异常和账号风险提示必须人工处理。
- 轻量模式最多扫描 `20` 页、保留 `100` 位客户；建议每批 `10–20` 位。
- 阿里页面结构变化后，按钮识别可能需要更新。
- 请遵守阿里国际站规则以及客户所在地区的营销和隐私要求，控制频率并尊重拒收意愿。
- 分享时发送完整 ZIP 包，不要只发送单个 `.js` 文件。

## 更新

收到新版后，解压到新文件夹，在扩展管理页点击本扩展的“重新加载”，再刷新阿里页面。`v1.2.0` 沿用 v1 本地设置空间，可以保留现有话术和队列设置。
